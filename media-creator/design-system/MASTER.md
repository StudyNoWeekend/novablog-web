# media-creator（帧记影像 · FrameWithMe 风格）设计系统

## 项目定位

面向视频创作者与影像爱好者的**深色影院感**内容主页：深蓝黑背景营造放映室氛围，长春花蓝主色呼应剪辑软件高光，暖黄手写字与涂鸦线条传递"手账式"创作温度。首页结构为 Hero 大图 → 精选作品 → 关于我 / 最新动态 / 我的装备三栏。

## 设计原则

- **影院氛围**：深色为默认（`:root`），浅色为可选（`.light`），配色对照参考图 FrameWithMe。
- **手写点缀**：标题关键词与批注使用手写字体（`font-hand`）与波浪下划线（`doodle-underline`），正文保持无衬线可读性。
- **卡片承载**：视频、文章、器材均为圆角卡片；hover 上浮 + 主色描边发光，无布局位移。
- **SVG 图标**：统一 lucide-react，社交平台按品牌映射，不用 emoji 充当图标。
- **可访问性**：正文/背景对比度 ≥ 4.5:1；可点击元素 `cursor-pointer` + `focus-visible` 环；触控目标 ≥ 44px。

## 色彩系统

### 深色（默认）

- **背景** `#0E1218`（深蓝黑）/ **卡片** `#151B24` / **抬升面** `#1B222D`
- **主文本** `#EEF2F8` / **次要文本** `#94A0B0`
- **主色** `#7285F7`（长春花蓝）：主按钮、活跃导航、链接、聚焦环
- **点缀** `#F5C451`（暖黄）：手写批注、星星涂鸦、高亮徽标
- **边框** `#232D3B` / **标签底** `#1D2634`

### 浅色（.light）

- **背景** `#F6F7FB` / **卡片** `#FFFFFF` / **主文本** `#171C26`
- **主色** `#5566E8` / **点缀** `#C98A12` / **次要文本** `#5A6678`（均满足对比度）

## 字体系统

- **正文/标题**：Geist + 中文系统栈（PingFang SC / Hiragino Sans GB / Microsoft YaHei）
- **手写**：Ma Shan Zheng（`--font-hand`，next/font 自托管），仅用于 Hero 关键词、批注、板块副标题
- **等宽**：Geist Mono（代码、数据）

| 层级 | 大小 | 用途 |
|------|------|------|
| Display | 3rem–4rem | Hero 主标题（手写关键词更大） |
| H1 | 2rem–2.5rem | 页面标题 |
| H2 | 1.5rem–1.875rem | 板块标题（配图标 + 手写副题） |
| Body | 1rem / lh 1.7 | 正文 |
| Small | 0.875rem | 标签、元信息 |

## 版式

- 容器：`max-w-7xl`，内边距 `px-4 sm:px-6 lg:px-8`
- 板块间距：`py-14 lg:py-20`；深浅交替底色 `bg-background` / `bg-card/40`
- 卡片圆角 `rounded-2xl`，按钮/标签 `rounded-full`，输入框 `rounded-xl`
- 阴影克制：默认无边框光，hover 用 `card-lift`（上浮 + 发光描边）

## 组件规范

- **导航**：固定顶栏 `bg-background/85 backdrop-blur`，左品牌（图标+双行标题），居中导航（活跃项主色+底部短横线），右侧搜索/主题切换/社交图标按钮（h-10 w-10 触控目标）
- **视频卡**：16:9 封面，hover 播放按钮浮现 + 封面微放大，标题 + 平台标签胶囊
- **按钮**：主按钮 `bg-primary` 白字；次按钮透明底 + 边框；均 `rounded-full`
- **三栏首页底区**：关于我（头像+手写招呼+信息行）/ 最新动态（缩略图+日期+标题）/ 我的装备（器材图拼贴+手写批注）

## 动画

- 微交互 150–300ms `ease-out`；transform/opacity 优先；骨架屏防跳动；`prefers-reduced-motion` 下移除装饰动画

## 反模式

- 不在深色底上使用低对比灰字（次要文本不低于 #94A0B0）
- 不用 emoji 当图标；不用渐变横幅堆砌
- hover 不做 width/height 或 scale 引发布局抖动的动画（封面图 scale 限于 overflow-hidden 容器内）
- 可点击元素不使用默认光标
