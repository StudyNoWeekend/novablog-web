# Media Creator Blog 设计系统

## 项目定位

面向视频观众与社交媒体追随者的明亮活泼风格内容主页，突出视频作品、文章动态与社交平台入口，营造短视频平台式的高饱和度、卡片化氛围。

## 设计原则

- **明亮优先**：以浅色背景为主，搭配高饱和度强调色，传递活力与创造力。
- **卡片化内容**：视频、文章、博主信息均以圆角卡片承载，阴影柔和，层次分明。
- **社交导向**：社交平台入口醒目、可点击，使用品牌色或统一图标风格。
- **动态感**：hover 时轻微上浮与阴影加深，模拟短视频平台的交互反馈。
- **可读性**：正文使用无衬线字体，标题加粗，行高宽松，适合长时间浏览。

## 色彩系统

### 主色

- **背景色**：`#FFFFFF`（纯白）/ `#FAFAFA`（页面底层）
- **主文本**：`#18181B`（zinc-900）
- **次要文本**：`#52525B`（zinc-600）
- **辅助文本**：`#A1A1AA`（zinc-400）

### 强调色

- **主强调色（视频红）**：`#FF4D6D` —— 用于主按钮、标签、活跃状态、关键 CTA
- **副强调色（活力橙）**：`#FF9F43` —— 用于次级高亮、悬停、社交入口
- **第三强调色（清新青）**：`#00D9FF` —— 用于装饰、渐变、徽章
- **渐变组合**：`linear-gradient(135deg, #FF4D6D 0%, #FF9F43 50%, #FFC312 100%)` —— 用于 Hero 背景装饰或重点标题

### 功能色

- **成功**：`#22C55E`
- **警告**：`#EAB308`
- **错误/破坏**：`#EF4444`
- **信息**：`#3B82F6`

### 中性色

- **卡片背景**：`#FFFFFF`
- **卡片边框**：`#E4E4E7`（zinc-200）
- **分隔线**：`#F4F4F5`（zinc-100）
- **输入框背景**：`#FAFAFA`

## 字体系统

- **标题字体**：`Geist`（已有）/ 系统无衬线回退
- **正文字体**：`Geist`（已有）
- **等宽字体**：`Geist Mono`（代码、标签、数据）

### 字号规范

| 层级 | 大小 | 字重 | 用途 |
|------|------|------|------|
| Display | 3rem / 48px | 800 | Hero 主标题（移动端 2.25rem） |
| H1 | 2.25rem / 36px | 700 | 页面标题 |
| H2 | 1.5rem / 24px | 700 | 区块标题 |
| H3 | 1.25rem / 20px | 600 | 卡片标题 |
| Body | 1rem / 16px | 400 | 正文 |
| Small | 0.875rem / 14px | 400 | 辅助信息、标签 |
| XS | 0.75rem / 12px | 500 | 徽章、时间戳 |

### 行高

- 标题：1.2
- 正文：1.65
- 辅助文本：1.5

## 间距系统

- 页面内边距：移动端 `px-4`，平板 `px-6`，桌面 `px-8`，大屏 `px-12`
- 最大内容宽度：`max-w-7xl`（1280px）
- 区块间距：移动端 `py-12`，桌面 `py-20`
- 卡片间隙：`gap-4` / `gap-6`
- 卡片内边距：`p-4` / `p-5`

## 圆角与阴影

- 卡片圆角：`rounded-2xl`（1rem）
- 按钮圆角：`rounded-full`（胶囊）或 `rounded-xl`
- 输入框圆角：`rounded-xl`
- 图片圆角：`rounded-xl`
- 卡片阴影：`shadow-sm` 默认，`shadow-lg` hover
- 导航栏阴影：`shadow-md`

## 组件规范

### 按钮

- 主按钮：渐变背景（粉到橙），白色文字，圆角全满，hover 时阴影加深
- 次按钮：白色背景，zinc-900 文字，zinc-200 边框
- 幽灵按钮：透明背景，hover 时 zinc-100 背景

### 卡片

- 视频卡片：封面 16:9，hover 时图片微缩放（scale 1.03），标题下方展示平台入口
- 文章卡片：封面 16:10 或 4:3，包含标题、摘要、分类标签、阅读量/评论数
- 博主卡片：头像 + 昵称 + 简介 + 社交图标横排

### 导航栏

- 固定在顶部，白色半透明背景 + 模糊
- 左侧博客标题/Logo，中部导航链接，右侧社交入口
- 移动端使用汉堡菜单

### 标签与徽章

- 分类标签：zinc-100 背景，zinc-700 文字，圆角全满
- 活跃标签：主强调色背景，白色文字
- 平台徽章：使用对应平台品牌色或统一 zinc 风格

## 响应式断点

- 移动端：`375px`（默认）
- 平板：`768px`（md）
- 桌面：`1024px`（lg）
- 大屏：`1440px`（xl/2xl）

## 动画与交互

- 默认过渡：`transition-all duration-200 ease-out`
- Hover 上浮：`hover:-translate-y-1 hover:shadow-lg`
- 图片缩放：`hover:scale-[1.03]`
- Focus 环：`focus-visible:ring-2 focus-visible:ring-primary/50`
- 页面加载：骨架屏或淡出出现

## 图标

- 统一使用 `lucide-react`，不使用 emoji
- 社交图标使用 Lucide 图标或平台 SVG，优先保持风格一致

## 反模式

- 不使用深色背景作为主色调
- 不使用 emoji 作为 UI 图标
- 不使用过低对比度的文字
- 不使用破坏布局的 transform 动画
- 不混合多种阴影风格
- 不将可点击元素设置为默认光标
